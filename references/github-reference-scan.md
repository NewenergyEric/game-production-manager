# GitHub 同类参考与本仓库取舍

- [gamedev-ai-agents](https://github.com/ilezhnin/gamedev-ai-agents)：把 GDD、planner、worker、QA 和 release gate 分开；本岗位吸收“阶段门和可玩里程碑”的契约思想，但只负责拆解与追踪。
- [open-game-skills](https://github.com/jammyfu/open-game-skills)：通过 dispatcher 选择最多三个专门 Skill；本岗位用岗位接口把市场、拆解和 Art Director 的输出接起来。
- [FunPlay Skill](https://github.com/FunplayAI/funplay-skill)：每个工作流都有验证面；本仓库为 SOW、依赖、验收和影响分析保留确定性检查。
- [codex-game-studios](https://github.com/hongyuanc/codex-game-studios)：提供阶段化游戏工作流的长文档样例；本岗位吸收其阶段门表达，但不声称拥有自动构建和发布能力。

当前取舍：项目经理输出执行契约、分工、回执和变更影响；未来 Agent 执行器必须另有明确权限、预算、停止条件和真实产物。
