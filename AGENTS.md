- Preserve this role's scope and existing user decisions. A recommendation, a plan, an execution result and an acceptance decision are different records.
- Keep the skill self-contained. Put conditional detail in references and preserve evidence/unknowns when transforming records.
- Python helpers use the standard library and support Python 3.10+. Run `python -m unittest discover -s tests -v` after code changes. Verify meaningful success and failure paths.
- REA is pinned to the lockfile. Real provider/target support needs actual evidence; do not infer it from CLI startup.
- Do not add private game files, credentials, account exports, local absolute paths or raw analysis outputs. Public examples must be original or independently shareable. `outputs/` and `private/` are ignored.
- Use a branch and PR for contributions; document behavior and validation. Do not expand a development request into automatic publication or external task assignment without authorization.
- Source catalog entries are not connected APIs. Verify access, fields, lineage and missing-data behavior before claiming a working connector.
